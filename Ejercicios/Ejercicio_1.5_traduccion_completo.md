# Ejercicio 1.5

**Ejercicio 1.5:** Enumera algunas herramientas (al menos 10) utilizadas comúnmente en el análisis de datos y menciona detalles de cinco de ellas.

## Herramientas comúnmente utilizadas en el análisis de datos

1. Microsoft Excel
2. Python
3. R
4. SQL
5. Tableau
6. Power BI
7. Apache Spark
8. SAS
9. MATLAB
10. Google Looker Studio
11. Jupyter Notebook
12. KNIME

## Detalles de cinco herramientas

| Herramienta | Detalles |
|---|---|
| **Microsoft Excel** | Es un programa de hojas de cálculo utilizado ampliamente para organizar, limpiar, analizar y visualizar datos. Ofrece fórmulas, tablas dinámicas, gráficos y funciones estadísticas. |
| **Python** | Es un lenguaje de programación utilizado comúnmente para el análisis y la visualización de datos. Bibliotecas como Pandas, NumPy, Matplotlib y Seaborn facilitan el trabajo con grandes conjuntos de datos. |
| **R** | Es un lenguaje de programación diseñado especialmente para la estadística y el análisis de datos. Se utiliza para modelos estadísticos, visualización de datos e investigación. |
| **SQL** | Es un lenguaje utilizado para trabajar con bases de datos. Permite recuperar, filtrar, combinar, modificar y resumir datos almacenados en bases de datos relacionales. |
| **Tableau** | Es una herramienta de visualización de datos e inteligencia empresarial. Permite crear paneles interactivos, gráficos e informes para identificar tendencias y patrones en los datos. |

## Conclusión

Estas herramientas ayudan a los analistas de datos a recopilar, procesar, analizar, visualizar e interpretar información para apoyar una mejor toma de decisiones.
