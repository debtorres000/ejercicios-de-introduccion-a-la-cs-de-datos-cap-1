Exercise 1.11
La pregunta pide mencionar únicamente cinco diferencias entre el trabajo de un analista de datos y un científico de datos. 
1.	Enfoque: El analista de datos analiza principalmente datos existentes, mientras que el científico de datos también se enfoca en predecir resultados futuros. 
2.	Herramientas: El analista utiliza principalmente Excel, SQL y programas de visualización; el científico también utiliza Python, R y aprendizaje automático. 
3.	Propósito: El analista explica qué ocurrió con los datos, mientras que el científico intenta predecir qué podría ocurrir. 
4.	Matemáticas: La ciencia de datos generalmente requiere matemáticas y estadística más avanzadas. 
5.	Modelos: Los científicos de datos desarrollan modelos predictivos y de aprendizaje automático, mientras que los analistas se enfocan más en reportes y análisis descriptivo.
