Exercise 1.7: Four differences between Data Analytics and Data Analysis /Ejercicio 1.7: Cuatro diferencias entre Análisis de Datos y Analítica de Datos

1. Alcance: El análisis de datos se centra en examinar y procesar conjuntos de datos específicos para hallar patrones; la analítica de datos es más amplia: incluye el análisis, además de herramientas, estrategias y contexto empresarial para la toma de decisiones.
2. Enfoque temporal: El análisis de datos se ocupa principalmente del pasado y el presente lo que sucedió; la analítica de datos también abarca tendencias futuras y predicciones lo que sucederá.
3. Objetivo: El análisis de datos se concentra en la inspección detallada y explicación de la información; la analítica de datos busca obtener conclusiones útiles y aplicarlas en procesos reales.
4. Complejidad y ámbito: El análisis de datos suele ser una tarea o paso específico y aislado; la analítica de datos es un ciclo completo y continuo que integra análisis, visualización, supervisión y más.
