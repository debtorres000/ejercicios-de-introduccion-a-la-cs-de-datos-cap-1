# Ejercicio 2.11: Aplicación en el cambio climático

1. **Pronósticos meteorológicos multivariados**: 
Aplica análisis de series temporales integrando variables como temperatura, humedad, presión atmosférica, viento y precipitación.

2. **Predicción de eventos extremos**: 
Analiza datos regionales para prever olas de calor o emergencias ambientales y establecer infraestructuras de prevención con antelación.

3. **Generación de energía renovable**: 
Pronostica la velocidad del viento para calcular la producción eólica esperada y planificar rutas de transporte marítimo.

4. **Análisis espaciotemporal**: 
Modela cambios ambientales a lo largo del tiempo y espacio (como la temperatura del mar o los niveles de contaminación) para detectar patrones climáticos.
