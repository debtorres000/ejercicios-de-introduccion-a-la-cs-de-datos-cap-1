# Ejercicio 1.4: Diferentes tipos de análisis de datos

Los diferentes tipos de análisis de datos ayudan en distintas etapas para mejorar la toma de decisiones en empresas y otras organizaciones. Algo que tienen en común todos los tipos de análisis es la disponibilidad de datos para aplicar el proceso de análisis. Mientras mejor sea la calidad de los datos, mejores serán las decisiones y los resultados.

## 1. Análisis descriptivo

**Diferencia:** Se enfoca en explicar **qué ocurrió** en el pasado. Utiliza datos históricos para identificar tendencias, patrones y resultados.

**Ejemplo práctico:** Una tienda analiza sus ventas del último año para determinar qué productos fueron los más vendidos y en qué meses tuvo mayores ingresos.

## 2. Análisis diagnóstico

**Diferencia:** Busca explicar **por qué ocurrió** un determinado evento o resultado. Analiza los datos para encontrar causas, relaciones y factores que influyeron en una situación.

**Ejemplo práctico:** Una empresa observa que sus ventas disminuyeron durante un mes y analiza los datos para determinar si la causa fue una reducción de clientes, problemas de inventario o un aumento de precios.

## 3. Análisis predictivo

**Diferencia:** Utiliza datos históricos, modelos estadísticos y técnicas de aprendizaje automático para estimar **qué podría ocurrir en el futuro**.

**Ejemplo práctico:** Una tienda utiliza los datos de ventas anteriores para predecir cuántas unidades de un producto necesitará durante la próxima temporada.

## 4. Análisis prescriptivo

**Diferencia:** Busca determinar **qué se debería hacer** para obtener un resultado favorable. Utiliza los resultados de los análisis y diferentes escenarios para recomendar acciones.

**Ejemplo práctico:** Una empresa analiza sus ventas, inventario y costos para recomendar cuánto producto debe pedir y cuándo debe realizar el siguiente pedido.

## Diferencias principales

| Tipo de análisis | Pregunta principal | Ejemplo |
|---|---|---|
| Descriptivo | ¿Qué ocurrió? | Analizar las ventas del año anterior. |
| Diagnóstico | ¿Por qué ocurrió? | Identificar la causa de una caída en las ventas. |
| Predictivo | ¿Qué podría ocurrir? | Predecir las ventas del próximo mes. |
| Prescriptivo | ¿Qué deberíamos hacer? | Recomendar cuánto inventario comprar. |
