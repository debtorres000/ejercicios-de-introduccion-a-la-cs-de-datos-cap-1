Ejercicio 1.13 
¿Cuáles son las diferencias clave entre análisis de datos y data mining? 
Menciona solo 5 diferencias. 


El data mining forma parte del análisis de datos, ambos tienen sus ramas de interes e implican diferentes procesos. 

El data mining encuentra patrones existentes dentro de los datos disponibles. El análisis de datos analiza los datos con diferentes métodos para recuperar información puntual. 

El data mining requiere el manejo de habilidades como matematicas, estadistica y machine learning. El proceso de análisis de datos requiere también de estadistica matemática, machine learning y conocimiento subjetivo. 

Mientras el data mining se enfoca casi exclusivamente a encontrar patrones de valor en los datos. El análisis de datos abarca desde la recoleccion de los datos, su limpieza y transformacion. 

Jerarquicamente, el data mining es una especialización del analisis de datos, que se enfoca en el hallazgo de patrones. 

El data mining busca descubrir patrones o relaciones desconocidas generalemente mediante algoritmos automáticos, el análisis, por otra parte puede responder preguntas ya planteadas (confirmatorio) o explorar de forma más general, no solo buscar patrones ocultos. (idea nueva, no la tenías)
